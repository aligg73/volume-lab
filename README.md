# Volume Lab

Mixed-reality Montessori volume lesson: melt the golden thousand cube into 1 litre, pour it between differently shaped vessels, and peel stickers off a jug to see water pressure, all with your bare hands via a tablet camera.

- `index.html`: hand-tracking mixed reality (MediaPipe + three.js). Needs https:// or localhost for the camera.
- `desktop.html`: mouse/touch 3D version with experimental WebXR mode.

Run locally: `python -m http.server 8000` → http://localhost:8000
